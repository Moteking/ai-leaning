# 「辞めたい…」人生の転機OS — サービス設計書

## サービス名案：**キャリモヤ（CareMoya）**

> 「辞めたいの正体、見つけよう」

---

## 1. コンセプト

「辞めたい」のに動けない人は、転職市場の10倍いる。
この**「モヤモヤ層」**を、毎週の感情記録から正確に分析し、
転職・副業・社内異動・スキルアップ・独立の**最適な出口に振り分ける**アプリ。

自分では求人を持たない。教育もしない。
**「辞めたい」という曖昧な感情の入り口だけを押さえる。**

## 6. AIエンジン設計

### 6.1 不満分類モデル

```
入力: 毎週の記録データ（満足度 + ストレス要因 + フリーテキスト）

処理:
├── テキスト感情分析（NLP）
│   → フリーテキストから感情の強度・方向性を抽出
├── パターン分類
│   → 不満を6カテゴリに分類
│   ├── 人間関係型（上司/同僚/部下）
│   ├── 報酬不満型（給与/評価/昇進）
│   ├── 成長停滞型（スキル/キャリアパス）
│   ├── 労働環境型（時間/場所/制度）
│   ├── 仕事内容型（やりがい/適性）
│   └── 組織不信型（経営/将来性/文化）
└── 時系列分析
    → 悪化傾向？改善傾向？一時的？慢性的？

出力: 不満の根本原因 + 推奨アクション
```

### 6.2 出口マッチングモデル

```
不満の根本原因 × ユーザー属性 → 最適な出口を推薦

ルール例:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

IF 人間関係型 AND 仕事内容への不満が低い
→ 社内異動 or 部署変更を最優先で提案
→ 「転職すると仕事内容のリスクが発生します」と注意喚起

IF 報酬不満型 AND 市場価値 > 現年収 × 1.2
→ 転職を提案（年収アップの確率が高い）
→ 最適なエージェントをマッチング

IF 成長停滞型 AND 年齢 < 35
→ スキルアップ → 副業 → 転職の順で提案
→ 「まず副業で実績を作ると、転職時の交渉力が上がります」

IF 組織不信型 AND 業界全体が縮小傾向
→ 業界チェンジを含む転職を提案
→ 「あなたのスキルが活きる成長業界はこちら」

IF 労働環境型 AND リモートワーク希望
→ フルリモート求人に特化して提案
→ 「今の会社にリモート制度を交渉するテンプレも用意」

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 6.3 「転職すべきタイミング」予測モデル

```
ユーザーの感情データ推移から「転職最適タイミング」を予測

指標:
- 満足度が4週連続で3以下 → 「慢性的不満」フラグ
- 急激に1-2に落ちた → 「イベント発生」フラグ（パワハラ等の可能性）
- 満足度が改善傾向 → 「転職不要」シグナル

転職推奨の条件:
① 慢性的不満 + 市場価値が現年収以上
② 不満の原因が「構造的」（会社の制度、業界の問題）
③ 年齢・スキルが市場で評価される範囲内
④ 本人の転職意思がある程度固まっている

→ すべて揃った場合のみ「今が動くタイミングです」とプッシュ
→ 安易に転職を勧めない（信頼の源泉）
```

## 8. 信頼設計（最も重要）

### 「転職を勧めないこと」が信頼の源泉

```
既存の転職サイト:
→ 転職してもらわないと儲からない
→ だから「転職した方がいいですよ」と煽る
→ ユーザーは「このサイトは転職させたいだけでは？」と不信感

キャリモヤ:
→ 送客以外にも収益源がある（BtoB、プレミアム、副業）
→ だから「今は転職しない方がいいです」と正直に言える
→ ユーザーは「このアプリは本当に自分のことを考えてくれている」と信頼

この信頼こそが最大の参入障壁。
```

### 具体的な信頼構築施策

```
1. 転職を止めた数を公開
   → 「今月、キャリモヤは1,200人の転職を止めました」

2. 出口ごとの満足度追跡
   → 転職した人の1年後満足度、異動した人の1年後満足度を公開
   → データで「安易な転職はリスク」を示す

3. エージェントの品質を可視化
   → 「このエージェント経由で転職した人の1年後定着率: 85%」
   → 質の低いエージェントを排除（ユーザー保護）

4. 企業の口コミではなく「感情データ」で評価
   → OpenWork等の口コミ: テキストで主観的
   → キャリモヤ: 在籍者の満足度推移という定量データ
```

```
- 大学・専門学校と連携（リスキリングの入り口）
- 海外展開
- KPI: 日本の「仕事の悩み」の入り口シェア20%
```

## 10. 競合との差別化

```
サービス          何を提供         キャリモヤとの違い
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

                                  → キャリモヤは「迷っている人」向け

ビズリーチ        スカウト型       ハイクラス限定。大多数は対象外
                                  → キャリモヤは全年収帯をカバー

OpenWork          企業口コミ       他人の意見。自分に合うかは別問題
                                  → キャリモヤは「自分の感情データ」が主語

ポジウィル        キャリアコーチング 月額5-10万円。高すぎる
                                  → キャリモヤは月480円で同等の分析

ミイダス           市場価値診断    一回きりの診断。継続性がない
                                  → キャリモヤは毎週データが蓄積
```
