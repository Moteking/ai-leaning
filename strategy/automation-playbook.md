# 自動実行プレイブック

このドキュメントは、マーケティング活動を最小人員で自動運用するための
具体的な手順書です。

---

## 週次ルーティン（所要時間：約5時間/週）

### 月曜（1.5時間）
| 時間 | タスク | ツール | 自動化レベル |
|---|---|---|---|
| 9:00-9:30 | 先週のKPI確認 | HubSpot Dashboard | 自動レポート確認のみ |
| 9:30-10:00 | 今週のブログ記事を最終確認・公開 | WordPress/CMS | 予約投稿（前週準備済） |
| 10:00-10:30 | SNS投稿確認（Buffer自動配信） | Buffer | 完全自動 |

### 火曜（0.5時間）
| 時間 | タスク | ツール | 自動化レベル |
|---|---|---|---|
| 9:00-9:30 | AIニュースチェック → SNS投稿作成 | Buffer | ニュース選定のみ手動 |

### 水曜（1時間）
| 時間 | タスク | ツール | 自動化レベル |
|---|---|---|---|
| 9:00-9:30 | メルマガ内容確認・配信承認 | HubSpot | テンプレ自動生成→承認のみ |
| 9:30-10:00 | リードスコア確認・HOTリードフォロー | HubSpot CRM | 通知は自動、対応は手動 |

### 木曜（1時間）
| 時間 | タスク | ツール | 自動化レベル |
|---|---|---|---|
| 9:00-10:00 | 翌週コンテンツの企画・ドラフト作成 | Notion/Google Docs | 手動（AI執筆支援活用） |

### 金曜（1時間）
| 時間 | タスク | ツール | 自動化レベル |
|---|---|---|---|
| 9:00-9:30 | 翌週のSNS投稿をBufferに登録 | Buffer | 手動（テンプレ活用） |
| 9:30-10:00 | 翌週のブログ記事を予約投稿 | WordPress | 手動 |

## 自動化ツール連携マップ

```
[コンテンツ作成]
    │
    ├── ブログ記事 → WordPress予約投稿
    │                    │
    │                    └──→ Buffer → LinkedIn自動投稿
    │                                  → X自動投稿
    │
    ├── メルマガ → HubSpot Email（テンプレート）
    │                    │
    │                    └──→ 毎週水曜10:00自動配信
    │
    └── ウェビナー → Zoom Webinar
                         │
                         ├──→ 申込確認メール（自動）
                         ├──→ リマインドメール（前日・1時間前：自動）
                         ├──→ サンクスメール（終了後：自動）
                         └──→ フォローシーケンス（自動）

[リード管理]
    │
    ├── フォーム送信 → HubSpot CRM自動登録
    │                    │
    │                    ├──→ タグ自動付与（流入元別）
    │                    ├──→ ナーチャリングシーケンス自動開始
    │                    └──→ スコアリング自動計算
    │
    ├── スコア≥50 → Slack通知（自動）
    │                  → 営業タスク自動作成
    │
    └── スコア<30（30日無反応）→ 再活性メール自動配信

[広告]
    │
    ├── Google広告 → 自動入札（コンバージョン最大化）
    │                 → コンバージョンデータ自動連携（HubSpot→Google）
    │
    └── リターゲティング → サイト訪問者リスト自動更新
```

## HubSpot ワークフロー設定一覧

### WF-01: ホワイトペーパーDLシーケンス
```
トリガー: フォーム「WP_DL」送信
→ タグ付与: 「WP_DL_{WP名}」
→ メールS1-1送信（即時）
→ 待機2日 → メールS1-2送信
→ 待機2日 → メールS1-3送信
→ 待機3日 → メールS1-4送信
→ 待機2日 → メールS1-5送信
→ 待機2日 → メールS1-6送信
→ 待機3日 → メールS1-7送信
→ リスト「ナーチャリング完了」に追加
→ 週次メルマガリストに追加
```

### WF-02: E-ラーニング体験シーケンス
```
トリガー: E-ラーニング無料登録
→ タグ付与: 「EL_TRIAL」
→ メールS2-1送信（即時）
→ 待機2日 → 条件分岐
  ├── ログイン済み → メールS2-2A（感想確認）
  └── 未ログイン → メールS2-2B（リマインド）
→ 待機3日 → メールS2-3送信
→ 待機2日 → メールS2-4送信
→ 待機3日 → メールS2-5送信
```

### WF-03: ウェビナーシーケンス
```
トリガー: ウェビナー申込フォーム送信
→ 申込確認メール（即時）
→ Zoomウェビナー登録API連携
→ 前日リマインドメール（自動）
→ 1時間前リマインドメール（自動）
→ ウェビナー後
  ├── 参加者 → サンクスメール + S3シーケンス開始
  └── 不参加者 → 録画案内メール + 次回案内
```

### WF-04: HOTリード通知
```
トリガー: スコア ≥ 50
→ Slack #sales チャンネルに通知
→ CRM担当者にタスク作成「{リード名}へ架電」
→ 「無料相談のご案内」メール自動送信
→ 3日後に条件分岐
  ├── 相談予約済み → タスククローズ
  └── 未予約 → フォロー電話タスク作成
```

### WF-05: 休眠リード再活性
```
トリガー: 30日間アクションなし & スコア < 30
→ 再活性メール1送信
→ 待機7日 → 条件分岐
  ├── 反応あり → 通常ナーチャリングへ復帰
  └── 反応なし → 再活性メール2送信
→ 待機7日 → 条件分岐
  ├── 反応あり → 通常ナーチャリングへ復帰
  └── 反応なし → 配信頻度を月1に変更
```
