# AIリスクコンサルティング マーケティング戦略書

## 1. エグゼクティブサマリー

福岡を拠点に、九州・西日本エリアを起点として全国展開するAIリスクコンサルティング事業の
マーケティング戦略。AI活用が急速に広がる中、多くの企業がリスク管理・ガバナンス体制の
構築に課題を抱えている。本戦略は「自動実行可能」なレベルで設計し、最小人員で最大効果を
実現する。

## 2. 市場分析

### 2.1 ターゲット市場
| セグメント | 企業規模 | 主な課題 | 優先度 |
|---|---|---|---|
| **Tier 1** | 大企業（従業員1,000名以上） | AIガバナンス体制の未整備 | ★★★ |
| **Tier 2** | 中堅企業（100〜999名） | AI利用ルールの不在 | ★★★ |
| **Tier 3** | 中小企業（30〜99名） | AI導入時のリスク認識不足 | ★★☆ |
| **Tier 4** | スタートアップ | プロダクトのAIリスク対策 | ★☆☆ |

### 2.2 ターゲットペルソナ

- **動機**: 取締役会でAIガバナンスの報告を求められている
- **情報源**: 日経新聞、ビジネスメディア、LinkedIn
- **決裁権**: 500万円まで

- **動機**: 社員のAI利用スキルにバラつきがあり、インシデントが発生
- **情報源**: HR系メディア、X（Twitter）、セミナー
- **決裁権**: 200万円まで

#### ペルソナC：情報システム部長 佐藤さん（45歳）

### 2.3 競合分析
| 競合タイプ | 強み | 弱み | 差別化ポイント |
|---|---|---|---|
| 大手コンサル（PwC, デロイト等） | ブランド力・包括的サービス | 高額・画一的 | 中堅向け価格帯で地域密着 |
| IT系コンサル | 技術力 | リスク・法務面が弱い | 法務×技術の統合アプローチ |
| 法律事務所 | 法的知見 | 実装支援が弱い | 実装まで伴走するワンストップ |
| 研修会社 | コンテンツ量 | AI特化の知見が浅い | AI特化の深い専門性 |

### 2.4 自社ポジショニング
**「九州発・中堅企業に寄り添うAIリスクの専門家」**

差別化の3本柱：
1. **地域密着**: 福岡を拠点に対面サポートも可能
2. **実装伴走型**: 方針策定だけでなく社内浸透まで支援
3. **段階的導入**: E-ラーニング → ルール策定 → ガバナンスの3ステップ

## 3. サービス設計とプライシング

### 3.1 サービスメニュー

#### プラン1: E-ラーニングサービス
| 項目 | 内容 |
|---|---|
| **概要** | AI利用リスクを体系的に学べるオンライン研修 |
| **対象** | 全社員（一般社員〜管理職） |
| **形式** | オンデマンド動画 + テスト + 修了証発行 |
| **コース構成** | 基礎編(3h)・管理職編(2h)・開発者編(3h) |
| **価格** | 月額1,500円/人（最低50名〜）または年額15,000円/人 |
| **年間最低契約額** | 90万円（50名×年額15,000円 + 初期設定10万円） |
| **リード獲得用** | 無料お試し：基礎編の第1章（30分）を無料公開 |

#### プラン2: 社内ルール策定支援
| 項目 | 内容 |
|---|---|
| **概要** | AI利用ガイドライン・運用ルールの策定支援 |
| **対象** | 経営企画部・情報システム部・法務部 |
| **期間** | 2〜3ヶ月 |
| **成果物** | AI利用ガイドライン、運用フロー、違反時対応マニュアル |
| **価格** | 150万円〜300万円（企業規模による） |
| **オプション** | 社内説明会の実施 +30万円 |

#### プラン3: ガバナンス策定支援
| 項目 | 内容 |
|---|---|
| **概要** | AI倫理・コンプライアンス体制の設計と実装支援 |
| **対象** | 経営層・取締役会 |
| **期間** | 3〜6ヶ月 |
| **成果物** | AIガバナンスフレームワーク、リスク評価基準、監査体制設計 |
| **価格** | 300万円〜800万円（企業規模・業界による） |
| **オプション** | 年間顧問契約 月額20万円〜 |

### 3.2 アップセルパス
```
E-ラーニング（入口）→ 社内ルール策定（中間）→ ガバナンス策定（上位）
      ↓                    ↓                       ↓
   顧問契約へ           年間保守契約へ          経営アドバイザリーへ
```

## 6. 自動化設計

### 6.1 マーケティングオートメーション構成
```
[ツール構成]
├── CRM/MA: HubSpot（無料〜Starter）
├── メール: HubSpot Email / Mailchimp
├── LP作成: HubSpot Landing Pages
├── SNS予約投稿: Buffer / Hootsuite
├── SEO: Google Search Console + Ahrefs(Lite)
├── 分析: Google Analytics 4
├── ウェビナー: Zoom Webinar
└── チャットボット: HubSpot Chatbot
```

### 6.2 自動化フロー
```
1. [リード獲得自動化]
   ・LP → フォーム送信 → HubSpot自動登録
   ・ホワイトペーパーDL → 自動メール配信開始
   ・ウェビナー申込 → リマインドメール自動送信

2. [ナーチャリング自動化]
   ・メールシーケンス自動配信（7通・14日間）
   ・スコアリング自動計算
   ・スコア閾値超え → 営業チームに自動通知

3. [コンテンツ配信自動化]
   ・ブログ記事 → SNS自動投稿（Buffer）
   ・SNS投稿 → 予約投稿で週5回自動配信
   ・ウェビナー → 録画を自動でYouTube公開

4. [レポーティング自動化]
   ・週次KPIレポート自動生成（HubSpot Dashboard）
   ・月次ROIレポート自動集計
```
