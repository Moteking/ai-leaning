```

│ ■ ファーストビュー                           │

│                                              │
│ ■ 診断の流れ                                 │
│ STEP1: 10問のアンケートに回答（5分）          │
│ STEP2: AIリスクスコアを即時算出               │
│ STEP3: 詳細レポートをメールでお届け           │

│ Q1. AI利用に関する社内ルールはありますか？    │
│ Q2. AI利用状況を把握する仕組みはありますか？  │
│ Q3. AI関連のインシデント対応手順はありますか？│
```

### 診断ロジック（10問×5段階評価）

| スコア | レベル | 推奨サービス |
|---|---|---|
| 40-50点 | A：先進的 | ガバナンス策定（高度版） |
| 30-39点 | B：標準的 | ガバナンス策定 |
| 20-29点 | C：発展途上 | 社内ルール策定 |
| 10-19点 | D：初期段階 | E-ラーニング + ルール策定 |
| 0-9点  | E：未着手 | E-ラーニング（まず基礎から） |
