活用の順番

迷ったらこの順番で進めてください
1. 初期セットアップ（ページ下部「初期セットアップ」参照）
HubSpot・Google広告・Buffer等のツール導入。4週間のチェックリスト通りに進めるだけ。
2. LP・コンテンツ制作（「LP設計」ページ参照）
ワイヤーフレーム通りにLPを制作。ホワイトペーパー第1号とブログ記事5本を作成。
3. メール自動化設定（「メール自動配信」ページ参照）
HubSpotにメールテンプレートとワークフローを設定。一度設定すれば自動で動く。
4. 広告・SNS開始（「広告設計」「SNS運用」ページ参照）
Google広告を開始し、SNSテンプレートを使って毎日の投稿をBufferに予約登録。
5. 週次ルーティン運用開始（「自動化プレイブック」参照）
週5時間のルーティンで回す。月曜〜金曜の曜日別タスクに従って運用。

競合分析

競合タイプ強み弱み自社の差別化
大手コンサルブランド力高額・画一的中堅向け価格帯で地域密着
IT系コンサル技術力リスク・法務面が弱い法務×技術の統合アプローチ
法律事務所法的知見実装支援が弱い実装まで伴走するワンストップ
研修会社コンテンツ量AI特化の知見が浅いAI特化の深い専門性

自社ポジショニング

「九州発・中堅企業に寄り添うAIリスクの専門家」

差別化の3本柱：
1. 地域密着: 福岡を拠点に対面サポートも可能
2. 実装伴走型: 方針策定だけでなく社内浸透まで支援
3. 段階的導入: E-ラーニング → ルール策定 → ガバナンスの3ステップ
