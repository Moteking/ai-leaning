# AI検索対応診断 — マーケティング戦略（費用0〜低コスト版）

運営：株式会社KAAAY ／ プロダクト：**AI検索対応診断**（https://aio-diagnosis.com ）
位置づけ：**無料診断ツールをリードマグネットにした、ECコンサル事業のリード獲得エンジン**

---

## 0. 戦略の基本思想

本サービスは「売り物」ではなく、**ECコンサル（改善実装・運用支援）への入口**です。
無料診断で見込み客の課題を可視化し、危機感とともにリード（会社名・メール）を獲得 → ナーチャリング → 個別相談 → 受注、という流れを、**できる限り広告費0で**回します。

採用するのは、世界的に実証済みの **「フリーツール・マーケティング（Free Tool as Lead Magnet）」** モデルです。

## 2. ターゲットと提供価値

### ターゲット（ペルソナ）
- **国内EC事業者**（Shopify / 楽天 / BASE / STORES / 自社EC）の運営・販促責任者
- **越境EC**を狙う/運用中の事業者（hreflang・多言語＝本診断の差別化項目）
- EC支援に関心のある**制作会社・代理店・コンサル**（パートナー候補にもなる）

### 刺さるフック（なぜ今か）
- **「SEOの次はAIO/GEO」**：ChatGPT検索・Perplexity・Google AI Overview の台頭で、検索行動が「AIが要約して答える」形に変化。**構造化データやAIクローラー許可をしていないECは、AIの回答に載らない＝機会損失**。
- この課題は**まだ大半の事業者が未対応**で、危機感の喚起がしやすい（＝診断の価値が高い）。
- 「無料・登録なしで今すぐ自社の点数がわかる」**ハードルの低さ**。

### メッセージ例（一貫して使う）
> 「あなたのECは、ChatGPTやGoogle AIに“見つけてもらえる”状態ですか?」
> 「SEO対策はしていても、AI検索対策（AIO）はまだの企業が大多数。30秒で無料診断。」

## 3. マーケ施策（費用0が中心・優先度順）

### ★施策A：プロダクト・レッド・グロース（ツール自体で広げる）— 最優先・費用0
1. **診断結果のSNSシェア導線**（要追加実装：ワンクリックでX/Facebookに「私のECのAI検索対応スコアは◯点でした」）
2. **「AI検索対応済み」バッジ**の配布（合格サイトに貼ってもらう→被リンク＆認知の自己増殖）
3. **比較・ランキング企画**：有名ECの診断結果を公開（「主要ECサイトAI検索対応度ランキング」）→ 話題化
4. **再診断リマインド**：改善後に再診断したくなる設計（メールで「30日後に再診断しましょう」）

### ★施策B：SEO / AIO コンテンツ（費用0・最重要の中長期資産）
- 自社サイトが診断項目を満たしている＝**AI検索に載りやすい**（ドッグフーディング）。
- 「**AI検索 対応**」「**LLMO / GEO / AIO**」「**ChatGPT 検索 EC**」「**構造化データ EC 商品**」等で記事を量産。
- **記事タイトル案（20本）**は §7 参照。
- ツールページ自体を「`AI検索 対応 診断 無料`」等で上位化（タイトル・見出し・FAQ構造化データを付与）。

### 施策C：オーガニックSNS（費用0）
- **X（旧Twitter）**：AI検索/ECのTIPSを毎日1投稿。診断のbefore/after、業界調査の小ネタ。
- **LinkedIn**：EC・マーケ意思決定者向けに、事例・調査データを発信（BtoBと相性◎）。
- **Threads / Instagram**：図解（インフォグラフィック）で「AIO 10のチェック項目」等。
- **TikTok / YouTube Shorts**：30秒で「あなたのECがAIに無視される理由」解説。
- 投稿テンプレは §8 参照。

### 施策D：コミュニティ＆無料PR（費用0）
- **note / Zenn / Qiita**：ノウハウを二次配信（Zenn/QiitaはAIクローラー実装の技術記事と相性◎）。
- **EC系コミュニティ**：Shopify/BASE/楽天運営者のFacebookグループ、Slack/Discord、商工会議所・創業支援。
- **無料プレスリリース**：valuepress（無料枠）等で「無料ツール公開」「調査リリース」を配信（PR TIMESは有料なので、まずは無料枠＋自社note）。
- **HARO型の取材対応**：メディアのEC/AI特集にコメント提供。

### 施策E：アライアンス／相互送客（費用0）
- **EC制作会社・Shopify Experts・広告代理店**：診断を共同提供し、改善案件を送客し合う。
- **税理士・補助金コンサル・商工会**：IT導入補助金などと絡め、EC事業者へ紹介。
- **メディア寄稿**：ferret / ECzine / ネットショップ担当者フォーラム等へ寄稿（被リンク＆認知）。

### 施策F：メールナーチャリング（ほぼ費用0）
- 現状：リードはGoogleスプレッドシートに蓄積。
- **無料で組める**：Googleフォーム回答→GAS（Google Apps Script）で自動サンクスメール、または Brevo/MailerLite の無料枠（〜数百〜数千通/月無料）で簡易ステップメール。
- シナリオ例：診断直後（詳細レポート再掲）→ 2日後（改善事例）→ 5日後（無料相談の案内）→ 隔週ニュースレター。
- ※**特定電子メール法**：営業メールは同意（オプトイン）と配信停止導線が必須。プライバシーポリシーに同意取得済み＝OK。配信停止リンクは必ず付ける。

### 施策G：無料ウェビナー／勉強会（費用0）
- 月1回「AI検索時代のEC集客（AIO入門）」をZoom/YouTube Liveで開催。
- 参加申込＝リード。診断ツールを当日デモして自分ごと化。

### 【参考】少額で効果を底上げできるもの（任意・後回し可）
- Google広告/Meta広告の少額テスト（1日500〜1,000円から、「AI検索 対応」指名・課題KW）。
- PR TIMES等の有料リリース（調査データが溜まってから）。

## 4. ファネル設計とKPI

```
認知(SNS/SEO/PR) → サイト訪問 → 無料診断実行 → メール登録(リード) → ナーチャリング → 無料相談 → 受注
```

| 段階 | 主要KPI | 費用0で測る方法 |
|---|---|---|
| 認知 | 表示回数・流入数・SNSエンゲージ | Vercel Web Analytics（無料・導入済み予定）、Search Console、各SNS標準分析 |
| 診断 | 診断実行数、完了率 | Vercel Analytics（イベント）、APIログ |
| リード | メール登録数、診断→登録CVR | スプレッドシート件数 |
| 商談 | 無料相談申込数 | CTAクリック、問い合わせ数 |
| 受注 | 受注数・LTV | 自社管理 |

**初期の現実的目標（例）**：月間 診断 300件 → リード 60件（CVR20%）→ 相談 6件 → 受注 1〜2件。
