`MARKETING.md` の戦略を「動く仕組み」にしたものの一覧です。費用0を基本に、外部アカウントが必要なものは**環境変数/シークレットを入れるだけ**で有効化できます。

|---|---|---|---|
| 1 | **結果のSNSシェア**（X/Facebook/LINE/LinkedIn） | ✅ 実装済み・稼働中 | なし（標準で有効） |
| 2 | **「AI検索対応」バッジ配布**（被リンク） | ✅ 実装済み `/badge` | なし |

## 1. 結果のSNSシェア（実装済み）
診断結果画面に X / Facebook / LINE / LinkedIn のシェアボタンを設置済み。
ユーザーが「自分のスコア」を共有することで、新規訪問者が流入する**バイラルループ**になります。
※リード獲得（メール登録）の前に表示しているため、登録しないユーザーも拡散に貢献します。

## 2. AI検索対応バッジ（実装済み）
- 配布ページ：`/badge`（フッター等からも導線追加を推奨）
- バッジ画像：`/api/badge?score=85`（SVG）
- 利用者が自社サイトに埋め込むと **当サイトへの被リンク** になり、SEO/AIOと認知に効きます。

## 3. 自動サンクスメール（実装済み・キー設定で有効化）
リードが登録された瞬間に、診断結果と無料相談CTA入りのメールを自動送信します。
コードは実装済みで、**Brevo（無料枠 300通/日）のAPIキーを入れるだけ**で稼働します。

### 有効化手順（5分・無料）
1. [Brevo](https://www.brevo.com/ja/) に無料登録
2. 送信元メール（`info@kaaay.co.jp`）を「送信者」として認証（Senders & IP → 送信者を追加 → 認証メールで承認）
3. SMTP & API → API Keys で **APIキー** を発行
4. Vercel → Environment Variables に追加：
   - `BREVO_API_KEY` = 発行したキー
   - `EMAIL_FROM` = `info@kaaay.co.jp`（任意・既定値あり）
   - `EMAIL_FROM_NAME` = `AI検索対応診断`（任意）
5. 再デプロイ → 以降、リード登録時に自動でメールが届きます

> キー未設定でもアプリは正常動作します（メールが送られないだけ）。
> 別プロバイダ（Resend等）に変える場合は `lib/email.ts` の中身のみ差し替え。
> ※営業色のある配信は特定電子メール法に注意（本文に配信停止導線あり）。

## 4. SNS定期自動投稿（X）
`automation/social/` を参照。GitHub Actions が毎日1本、`x-queue.txt` から投稿します。
X APIキー（4つのシークレット）をGitHubに登録すれば稼働。未登録ならスキップ（無害）。

## 5. コンテンツ運用カレンダー
`CONTENT_CALENDAR.md` に90日分の発信計画。SNS素材・記事ネタはここから供給。

## 6. 再診断リマインド（将来）
30日後の自動リマインドは、リードを後から参照できるDBが必要です。
現状リードはGoogleスプレッドシート保存のため、対応する場合は **Vercel Postgres + Vercel Cron** への移行を推奨（別途実装可）。
